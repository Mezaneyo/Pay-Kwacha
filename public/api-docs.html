API Documentation

Accept mobile money payments via Airtel Money and TNM Mpamba using a simple REST API.

Introduction

The PayKwacha API lets you:

  • Send payment prompts directly to your customers' phones
  • Collect payments via Airtel Money or TNM Mpamba
  • Check payment status in real-time
  • Receive webhook notifications when payments complete
Base URL: https://pay-kwacha.vercel.app

Authentication

Every request to /api/payment requires your unique API key. You'll find your key in the Dashboard → API tab.

Quick Start

Send your first payment in 3 steps:

1. Include the API

fetch('https://pay-kwacha.vercel.app/api/payment', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        apiKey: 'YOUR_API_KEY',
        phoneNumber: '0995514049',
        amount: '50',
        provider: 'AIRTEL_MWI'
    })
})
.then(r => r.json())
.then(console.log);

2. Customer confirms

The customer receives a payment prompt on their phone. They enter their PIN to authorize.

3. Check status

Poll the status endpoint until you see success or failed.

Initiate Payment

POST/api/payment

Sends a payment prompt to the customer's phone via mobile money.

Request Body

FieldTypeRequiredDescription
apiKeystring✅ YesYour PayKwacha API key
phoneNumberstring✅ YesCustomer's phone (e.g., 0995514049)
amountstring✅ YesAmount in MWK (minimum 50)
providerstring✅ YesAIRTEL_MWI or TNM_MWI
emailstringNoCustomer email (optional)

Example Request

curl -X POST https://pay-kwacha.vercel.app/api/payment \
  -H "Content-Type: application/json" \
  -d '{
    "apiKey": "PK_1791213007088_O85X46KX",
    "phoneNumber": "0995514049",
    "amount": "50",
    "provider": "AIRTEL_MWI"
  }'

Success Response

{
  "success": true,
  "chargeId": "PC-1791213071566-decea9",
  "status": "PENDING",
  "message": "Prompt sent to 995514049",
  "data": {
    "status": "success",
    "data": {
      "charge_id": "PC-1791213071566-decea9",
      "ref_id": "21707502011",
      "status": "pending"
    }
  }
}

Error Responses

// Missing API key (401)
{ "success": false, "error": "Missing API key" }

// Invalid key (401)
{ "success": false, "error": "Invalid API key" }

// Wrong phone format (400)
{ "success": false, "error": "Invalid phone (10 digits, expected 9)" }

// Amount too low (400)
{ "success": false, "error": "Amount must be at least K50" }

Check Payment Status

GET/api/payment-status/:chargeId

Check the current status of a payment using the chargeId returned from /api/payment.

Example Request

curl https://pay-kwacha.vercel.app/api/payment-status/PC-1791213071566-decea9

Response

{
  "success": true,
  "chargeId": "PC-1791213071566-decea9",
  "status": "success",
  "data": { /* full PayChangu response */ }
}

Status Values

StatusMeaning
pendingWaiting for customer to authorize
successPayment completed successfully
failedPayment failed (wrong PIN, insufficient balance, etc.)

Webhooks

PayKwacha can notify your server when payments complete by sending a POST request to a URL you provide.

Webhook URL: https://pay-kwacha.vercel.app/api/webhook/paychangu

Webhook Payload

{
  "charge_id": "PC-1791213071566-decea9",
  "status": "success",
  "amount": "50",
  "currency": "MWK",
  "mobile": "995514049"
}

Handling Webhooks

Your endpoint should:

  1. Respond with HTTP 200 immediately
  2. Process the payment asynchronously
  3. Credit the customer's account based on charge_id
